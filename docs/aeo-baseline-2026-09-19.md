## What stands out

- **Extremely low CTR on high-impression queries.** "marc andreessen" has 34,845 impressions but only 60 clicks (~0.17% CTR). "burbn" has 9,629 impressions for 14 clicks. "geocities" has 6,345 for 18. These read like queries where an AI Overview or a direct answer box is satisfying the searcher without a click-through — which is the exact AEO problem this plan exists to address, visible in the site's own data rather than inferred.
- **Year-query demand is already real and already ranking.** Nearly every "internet in [year]" / "[year] internet" phrasing from 1994–2012 appears in the top 50, each with decent impressions and low-but-nonzero clicks. This is direct evidence *for* plan item 8 (turning the year pages into answerable summaries) — the demand these pages should be capturing is already showing up in Search Console.
- **Question-phrased queries are present and underserved.** "when was javascript created" (1,309 impressions, 10 clicks), "why was javascript created" (178 impressions, 10 clicks), "what was the internet like in [year]" for several years. These are the queries most likely to be answered by an AI system directly rather than clicked.
- **Not yet captured:** the Pages tab (which URLs are getting the impressions), and an AI-referrer segment in GA4. Still needed to complete item 0.

## Correction to the plan, made from this data

**The "internet in [year]" content already exists and is already well-headed.** All 19 posts in `src/posts/years/` (`internet-1994.md` through `internet-2012.md`) have 3–6 `##` headings each — I had not checked this file specifically when I wrote item 8, and wrongly conflated it with the 27 near-identical files in `src/pages/yearpages/`, which really are unheaded link-lists (those render `/tags/[year]/`, a different URL pattern). The `internet-[year]` *posts* are exactly the content the top-query data pointed to, and they were already done. Item 8 has been narrowed to the smaller `/tags/[year]/` archive pages, which matter far less than originally framed.

**The heading correlation is real and worth acting on.** Cross-referencing the worst-CTR, high-impression pages against the repo:

| Page | Impressions | CTR | `##` headings |
|---|---|---|---|
| the-golden-age-of-microblogging | 57,409 | 0.06% | 0 |
| marc-andreessen-2004 | 45,801 | 0.19% | 0 |
| 1995-the-birth-of-javascript | 40,777 | 0.39% | 0 |
| wayback-machine-launch-2001 | 13,706 | 0.09% | 0 |
| 1993-mosaic-launches-and-the-web-is-set-free | 11,658 | 0.09% | 0 |
| bowienet-the-inside-story-of-its | 5,426 | 0.39% | 0 |

Every one of the six worst-converting high-impression pages has zero subheadings. By contrast the `internet-[year]` posts, which all have headings, average roughly 1.3% CTR — more than triple. This is a correlation from six data points on one site, not causal proof, but it's the strongest evidence in this plan for item 1, and it names the exact posts to do first.
